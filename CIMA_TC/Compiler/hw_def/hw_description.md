# Hardware Description
## CIMA架构NPU

### 总述

CIMA 是一款基于 RRAM 存算一体技术的高性能综合神经网络计算核架构，能支持神经网络算法的端到端高性能计算，支持多种神经网络算法并发执行，实现复杂应用场景下一系列神经网络处理任务的协同计算。

### 芯片架构描述

如下图，CIMA 为基于4*9 mesh拓扑的片上互联 NoC 架构。36个core中，Core0_4（别名 HOSTI）通过 PCIe 与 HOST/上位机进行交互，Core3_4（别名DDRI）负责与 DDR 外部存储器交互，两者一般用作数据输入、结果输出或中间结果中转/暂存。Core0_3，Core0_3, Core0_5，Core3_4, Core3_5，只提供数据路由功能；其他31个Core均为计算核，同时具有数据计算和路由能力。

### 计算核架构

每个计算核包含一个共享 DMEM 存储（存储容量为2^14=16384个4bit数），数据流调度单元，数据流重整单元，1个DMAC数字计算单元，1个mfop上下采样单元，并在 ESWN 4个方向分别绑定4个激活单元和4个基于 RRAM 的 PE 计算单元。

#### PE计算单元

每个PE计算单元包含16个规格为576*128的逻辑crossbar（XB）RRAM阵列，支持两个计算线程（两个计算任务）。每一个线程可以在列方向联合1，2，4个逻辑XB进行矩阵乘法计算，输入、输出以及权重存储的数据位宽均为4bit。在上述限制以及实际设计下，PE可实现的计算规格组合如下表：

| k_size | stride | cin            | cout           | pad  |
| ------ | ------ | -------------- | -------------- | ---- |
| 1      | 1/2    | 64/128/256/512 | 64/128/256/512 | 0    |
| 3      | 1/2    | 64             | 64/128/256/512 | 0/1  |

注：RRAM XB的计算方式：RRAM XB可以实现高效矩阵向量乘法计算，通过将静态权重预先编程为RRAM器件电导，将向量表示为输入电压，通过基尔霍夫电流定律在每一列得到相应的电流值，通过ADC转换为计算结果。可以用来部署神经网络中的卷积、全连接等算子。部署卷积权重时，需要将卷积核按照 img2col 方式展开成二维矩阵，即[cout, cin, kh, kw] -> [kh\*kw\*cin, cout]（如[cout, cin, kh, kw]=[128, 64, 3, 3]的卷积核，展开为[576, 128]，恰好可部署在一个XB上）；部署全连接权重即直接部署二维矩阵。

PE单元后附有一组存储scale和offset buffer，可以实现等价的BN操作。

#### DMAC计算单元

每个Core内包含1个DMAC数字计算单元，由于规模较小，一般只用于计算首尾层等对精度要求较高的层。DMAC阵列与RRAM XB原理类似，支持两种阵列形状的切换：256\*64和512\*32，输入输出以及权重存储的数据位宽均为8bit，仅支持单线程。可实现的计算规格组合如下表：

| k_size | stride | cin               | cout | pad     |
| ------ | ------ | ----------------- | ---- | ------- |
| 1      | 1      | 32/64/128/256/512 | 32   | 0       |
| 1      | 1      | 32/64/128/256     | 64   | 0       |
| 3      | 1/2    | 3/4/8/16/32       | 32   | 1       |
| 3      | 1/2    | 3/4/8/16          | 64   | 1       |
| 5      | 1/2    | 3/4/8/16          | 32   | 1/2     |
| 5      | 1/2    | 3/4/8             | 64   | 1/2     |
| 7      | 1/2    | 3/4/8             | 32   | 1/2/3   |
| 7      | 1/2    | 3/4               | 64   | 1/2/3   |
| 9      | 1/2    | 3/4               | 32   | 1/2/3/4 |

#### mfop上下采样单元

   可支持上采样和maxpooling/averagepooling下采样操作，输入数据为4bit，支持两个线程，可实现的计算规格组合如下表：

| sample_method   | k_size | stride | cin/cout            | pad   |
| --------------- | ------ | ------ | ------------------- | ----- |
| up_sample       | 2/3/4  | 1      | 64/128/256/512/1024 | 0     |
| up_sample       | 5      | 1      | 64/128/256/512      | 0     |
| maxpool/avgpool | 2      | 1      | 64/128/256/512/1024 | 0     |
| maxpool/avgpool | 3/4    | 1/2    | 64/128/256/512/1024 | 0/1   |
| maxpool/avgpool | 5      | 1/2/4  | 64/128/256/512      | 0/1/2 |

#### 激活单元

每个方向有一个ReLU激活单元，和一个4bit-16值查找表（用于实现其他激活函数）
